# Branding source and approximations

The user-supplied 1254×1254 “IndiDraw Tricolour Brand Styleboard.png” is authoritative. The approved brush/person symbol and wordmark were cropped directly from that raster source, not redesigned. The primary tagline is the requested “Where ideas take shape.” rather than the styleboard's older “Ideas to Illustrations”. App icons use the same symbol on a white square. No artificial vector tracing is presented as original artwork. The logo has a white raster background, so dark mode gives it a small light backing.

Palette: saffron #FF9933, Indian green #138808, deep blue #0F3B82, warm yellow #FFC107, soft off-white #F8F9FA, slate gray #4B5563. The interface uses a system sans-serif stack; the raster wordmark retains the supplied typography. Dark-mode key navigation uses a lighter blue for readability while primary buttons retain the deep blue background.

No government or military symbols are included. “A Soldier’s Enterprise” appears discreetly in the website footer and founder story, not in the editor. The IndiDraw name, logo and wordmark are the project owner's brand assets. They are published with the source so the app can be built as-is, but they are not covered by the MIT code licence and no trademark rights are granted. If you fork IndiDraw to run your own service, please replace the name and logo.
